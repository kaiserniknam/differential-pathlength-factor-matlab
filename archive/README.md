# Development archive

This directory preserves near-duplicate and alternative versions supplied by
the authors. Files are clustered by scientific purpose and retain their
original names for traceability. They are not the recommended entry points and
still contain historical machine-specific paths.

- `parameter_sweep_versions/` — versions 1–3 and 5–8 of the optical sweep.
- `experimental_versions/` — earlier and reflectance-focused validation code.
- `recovery_alternative_G/` — alternative recovery modes, including the
  distance-dependent definition `G(d) = OD(mu_a = 0,d)`.
